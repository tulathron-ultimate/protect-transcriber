# Vault notes

`Protect Transcriber.md` is written for an Obsidian vault rather than for this
repo: frontmatter, tags, and `[[wikilinks]]` to the usual homelab notes.

Copy it into the vault, e.g.:

```powershell
Copy-Item -Path '.\docs\obsidian\Protect Transcriber.md' `
          -Destination 'C:\Users\tulat\OneDrive\Vaults\Projects\' -Force
```

It is kept here as well so the findings travel with the code.
